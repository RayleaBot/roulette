## 设置页重设计

验证日期：2026-10-02。测试环境：Windows x64，Node 26.10.0、pnpm 11.25.0、Go 1.27.1，Microsoft Edge 154.0.4258.48（Playwright）。

- Vue 类型检查、10 项交互/模型/推演测试、生产构建通过。新增覆盖：口令增删与前缀拒绝、群按规则单元单独设置与恢复默认、群专用台词只写入该群、推演在弹膛很少时不提前结束、提前结束开关决定推演结局。
- 本地测试宿主连接真实插件进程，在 1880×960（宿主 1920×1080 下的 iframe 尺寸）、1440×900、1280×800 与 1000×900 检查亮暗主题、规则联动高亮、群设置与台词就地编辑、超时结局、无效设置暂停推演并可跳转修正、页内确认条；无水平溢出、无控制台错误。
- 键盘：Tab 顺序与视觉顺序一致并显示 3px 焦点轮廓；回车打开台词编辑并聚焦输入框，Esc 关闭并把焦点还给编辑按钮；空格切换开关；确认条出现时焦点落在确认按钮，Esc 取消并回到触发按钮。
- Impeccable 检测的唯一发现（时限进度条的宽度过渡）已改为 transform，复测无发现。独立页面评审给出 fix，8 项问题经复核全部 resolved；复核指出的两处回归（台词编辑框的双层边缘、1280 宽度下范围上限单独换行）已修复并重新截图，未再送评审打分。
- 整理设计记录时发现并修复三处问题：系统暗色回退缺少三项颜色变量，暗色高亮的文字对比度不足，两个结束开关未接入联动高亮。修复后在系统暗色且宿主未设置主题时复查了当前范围与机器人头像，也复查了开关聚焦时推演中对应消息的高亮。
- 安装包未随本次重设计重新构建；发布前按 README 重新打包。

- 宿主插件页 CSP 允许 HTTPS 图片与音视频（RayleaBot 主仓库契约、服务端与测试同步修改）；本地测试宿主同步该策略。
- Vue 类型检查、12 项测试（新增：唯一可用机器人自动选中并显示 QQ 头像地址、已单独设置的群直接打开而不重复添加）与生产构建通过，Impeccable 检测无发现。
- 本地测试宿主连接真实插件进程，在 1880×960 下检查亮暗主题的悬浮面板：两个机器人与两个群的头像均从 QQ 头像服务加载成功，无 CSP 报错或控制台错误；添加后左栏与检查器显示群头像。
