# 设置页设计

界面面向桌面端机器人管理员：低频打开，主要调整默认规则，偶尔为少数群单独设置。视觉系统见 `DESIGN.md`，方向约定见 `ui/.impeccable/surfaces/ui-src.md`。

## 页面结构

- 管理页分两页：「轮盘设置」（全局）只编辑默认规则与台词；「群覆盖」（按机器人账号）只编辑当前账号的群覆盖，账号由宿主在页面上方切换。群覆盖页的默认规则以「全局默认值（只读）」显示，修改回到轮盘设置页。
- 左栏「规则范围」：轮盘设置页只有默认规则，底部是「历史数据与归属」入口；群覆盖页列出当前账号单独设置的群，显示群头像、群名、群号、覆盖摘要与数量，底部「为某个群单独设置」打开悬浮面板。
- 历史数据与归属：列出缺少机器人账号、或账号已不在宿主目录中的群覆盖。缺少账号的记录可选择目录中的 OneBot11 账号绑定；账号已不在目录中的记录只能删除。
- 添加群悬浮面板：直接列出当前账号的群（头像、群名、群号），按群名或群号查找，已单独设置的群标为「已单独设置」，确认按钮变为「打开已有设置」。查询前后重新读取账号所在连接；账号离线或无连接时提示群列表不可查询。单击选中、双击或按钮添加，Esc 或遮罩关闭并把焦点还给触发按钮。头像直接加载 QQ 头像服务，失败时显示首字头像。
- 当前账号是 QQ 官方机器人时，群覆盖页提示轮盘仅支持 OneBot11 群聊，不提供编辑。
- 中栏「推演一局」：按当前范围的有效规则与台词模拟一局群聊。场景包括命中禁言、命中豁免、提前结束、超时（不惩罚、禁言发起人、发起人豁免三种结局）与管理员停止，可换一组示例数值。点机器人消息就地编辑对应台词。
- 右栏规则检查器：首枪中弹、禁言、时限速览；开局口令、装填、惩罚、收局分组；底部固定保存区显示已同步、有未保存更改或已保存待应用，列出需要修正的设置并可跳转。

## 交互约定

- 规则联动：聚焦或悬停一条规则时，推演中对应的数字与提示高亮；数值变化时对应数字闪一下。减少动态效果时改为静态标记。
- 群设置按规则单元继承：弹膛、子弹、禁言各自整组，时限与两个结束开关单独。「单独设置」复制当前有效值，「恢复默认」删除该单元的全部覆盖字段。旧数据中只覆盖单个字段的群显示为「本群」并保留原字段。
- 台词：默认范围可恢复插件默认台词；群范围通过「本群专用台词」开关决定是否覆盖，关闭时显示并跟随默认台词。
- 推演中的群友、对话和抽取值都是示例，页面始终标注不会发送；推演不连接开局、消息或禁言。
- 规则有误时推演暂停并说明原因，修正后恢复。

## 验收

在宿主 1920×1080 桌面工作区（iframe 约 1880×960）检查亮暗主题、群设置、台词编辑与保存状态。键盘可完成全部操作，错误关联字段，无外部字体、图片或脚本。1440 与 1280 宽度保持三栏，1080 以下改为上下堆叠。
